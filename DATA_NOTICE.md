# Game Data Notice

This project uses a small processed subset of item, recipe, and building facts derived from the localized `CommunityResources/Docs` files distributed with Satisfactory for community tools.

- Raw localization exports are deliberately excluded from this repository.
- The processed files contain identifiers, display names, recipe quantities, rates, and building statistics required by the calculator.
- Game-related names, data, and trademarks remain the property of their respective owners and are not covered by this repository's MIT License.
- This project is unofficial and is not affiliated with or endorsed by Coffee Stain Studios.

Users who regenerate the processed data should use the `CommunityResources/Docs` files from their own installed copy of the game and run `tools/import_satisfactory_data.py`.
