# Security Policy

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Use GitHub's private vulnerability reporting feature when available, or contact the repository owner privately through their GitHub profile.

Include the affected version, reproduction steps, expected impact, and any suggested mitigation. Reports will be acknowledged as soon as practical.

## Release verification

Official binaries are published only in this repository's GitHub Releases. Each release includes a SHA-256 checksum, and automated releases include GitHub build provenance attestation.
